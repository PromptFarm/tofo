# Security Policy

## Reporting a vulnerability

Please **don't** open a public issue for security vulnerabilities.

Instead, use GitHub's [private vulnerability reporting](../../security/advisories/new) for this repository. If that's not available, email the maintainer directly (see the GitHub profile linked on commits) with a description of the issue and steps to reproduce.

This is a small, early-stage project maintained without a dedicated security team — there's no bug bounty and no guaranteed response time, but real reports will be read and acted on.

## Scope

TOFO runs entirely on your own machine: local SQLite database, no cloud backend, no account. The main things worth reporting are:

- Anything that lets a project you open, or content generated by a model, execute code or read files outside TOFO's own data directory
- Credential handling — API keys entered in Settings are stored locally; a bug that leaks them elsewhere (logs, network requests to anything other than the configured provider) is a real issue
- Anything in the bundled desktop shell (`apps/desktop`) that weakens the usual guarantees of running a downloaded Windows/macOS app

## Supported versions

Only the latest release is supported. If you're on an older version, please update and confirm the issue still reproduces before reporting.
